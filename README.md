# 简图 · 数学画板

面向高中生和非数学专业大学生的本地数学作图 Web 应用。输入表达式即可在 2D/3D 坐标系中绘图，也可以直接在坐标系里画直线、圆、椭圆、抛物线和双曲线；支持参数、导函数、多条切线、直线 n 等分点、动点轨迹和轨迹方程推导。

- **手机优先**：全屏画布 + 可收起底部面板 + 大触控目标
- **离线运行**：安装依赖后不访问 CDN、外部字体或接口
- **绝不崩溃**：表达式、单条曲线、JSXGraph 元素和 3D 场景都有错误隔离
- 2D 渲染：[JSXGraph](https://jsxgraph.org/)
- 表达式解析/求导/化简：[mathjs](https://mathjs.org/)
- 公式排版：[KaTeX](https://katex.org/)
- 3D：[Three.js](https://threejs.org/)

## 快速开始

### 环境

- Node.js 20+（建议 22/24）
- Chrome / Edge 最新版
- 手机端：iOS Safari 16+ / Android Chrome 最新版

### 启动

```bash
npm install
npm run dev
```

浏览器打开 <http://127.0.0.1:5173/>。

Windows 也可以双击 `启动.bat`（首次运行会自动安装依赖并打开浏览器）。

### 手机访问

手机和电脑连同一个 Wi-Fi：

1. 在电脑上执行 `npm run dev`（项目脚本已默认监听 `0.0.0.0`）；
2. 终端会打印 Network 地址，例如 `http://192.168.1.23:5173/`；
3. 手机浏览器打开这个地址；
4. 如果访问不了，请允许 Windows 防火墙对 Node.js 的局域网访问。

### 生产构建

```bash
npm run build
npm run preview
```

构建产物在 `dist/`，可由任意静态文件服务器托管。

## 功能

### 2D 表达式

- 显式函数 `y = f(x)`
- 参数曲线 `(x(t), y(t))`
- 隐式方程 `F(x, y) = 0`（也可写带等号的形式）
- 导函数：开关后显示公式和同色虚线
- 每条曲线可添加**多条切线**，切点独立拖动
- 多曲线独立颜色、显隐、删除

### 参数

- 表达式中未被保留的单字母自动识别为参数
- 数字输入 + 滑条，拖动滑条实时更新
- **每个输入框最多 3 个参数**
- 同名参数共享数值
- `e` 是自然常数，不能作为参数；参数建议使用 `a、b、c、k、m` 等

### 手绘几何

- 直线、圆、椭圆、抛物线、双曲线
- 两次点击创建（双曲线先选横向/纵向）
- 锚点可拖动，图形和方程实时更新
- 每条图形可单独切换是否显示方程
- 显示方程时画布上有轻量标签，卡片里有完整 KaTeX 公式
- 椭圆/双曲线保持轴对齐，不做任意旋转

### 等分点、动点与轨迹

- 直线设置 n（2～20），可用开关显示/隐藏 n−1 个等分点（默认隐藏）
- 选择 A 或 B 为动点，另一端固定
- 动点可以绑定到已有函数、参数曲线或手绘图形
- 支持播放/暂停、记录轨迹、清除轨迹
- 固定端点移动时方程随位置更新

### 轨迹方程

固定端点 Q、动点 M 沿曲线运动，P 为第 k 个 n 等分点：

```
P = Q + λ(M - Q),  λ = k/n
```

应用会给出：

- 函数驱动：显式轨迹方程
- 圆/椭圆/抛物线/双曲线驱动：标准方程
- 隐式方程驱动：代入化简后的隐式方程
- 参数曲线驱动：参数形式轨迹方程
- 推导步骤、第 k 个点的切换、参数变化后的实时更新

限制：只针对上述“固定端点 + 动点沿曲线 + 等分点”的构造；不推导任意几何依赖图的轨迹方程；参数曲线不做任意隐式化。

### 3D

- 显式曲面 `z = f(x, y)`
- 参数曲面 `(x(u,v), y(u,v), z(u,v))`
- 空间曲线 `(x(t), y(t), z(t))`
- 鼠标/手指轨道旋转、滚轮/双指缩放、重置视角
- 独立颜色、显隐、删除、范围与精度设置
- 参数与 2D 共享；每个输入框最多 3 个参数
- 3D 保持基础能力，不做 3D 切线等进阶功能

## 输入语法

| 输入 | 含义 |
|---|---|
| `x^2` | 幂 |
| `sin(x)`、`cos(x)`、`tan(x)` | 三角函数（弧度） |
| `asin(x)` / `arcsin(x)` | 反三角函数 |
| `ln(x)` | 自然对数 |
| `lg(x)` | 以 10 为底的对数 |
| `sqrt(x)`、`abs(x)`、`exp(x)` | 常用函数 |
| `pi`、`π` | 圆周率 |
| `e` | 自然常数 |
| `2x`、`2(x+1)` | 隐式乘法 |
| `x*y` | 两个字母相乘请写乘号 |
| `x^2 + y^2 = 4` | 隐式方程 |

也支持 `y = ...`、`z = ...`、`x(t) = ...` 等常见左侧写法。全角括号、`×`、`÷`、`−`、`π`、`²` 等会自动规范化。

函数名后必须加括号，例如写 `sin(x)` 而不是 `sinx`。

## 交互

### 手机

- 画布：单指拖动平移、双指捏合缩放；点、锚点可直接拖动
- 底部面板：点“对象”或拖动把手展开/收起；编辑时输入框会自动滚入可视区
- “添加”打开对象菜单，“画图”打开图形工具盘
- 工具选中后点两下画布即可创建；点“取消”退出
- 横屏时展开的面板会变成右侧面板，保留左侧图像区

### 桌面

- 左侧对象栏，右侧画布
- 滚轮缩放、拖空白平移、右下角缩放/复位/吸附
- 画图工具位于对象栏顶部

## 数据与隐私

- 画板自动保存到浏览器 `localStorage`
- 不包含账号、云同步或任何外部接口
- 运行时不发起外部网络请求（KaTeX 字体随构建本地提供）
- “帮助 → 清空画板”可清除当前画板

## 已知边界

- 每个输入框最多 3 个参数；参数名只支持单个字母
- 圆锥曲线轴对齐，不旋转
- 轨迹方程为固定端点 + 动点沿曲线 + 等分点的构造，参数曲线给参数形式
- 每条曲线可有多条切线；直线对象不提供切线
- 3D 为基础曲面/曲线浏览，不含 3D 切线
- 不做不等式区域、积分、极坐标、向量场、图片导出、云同步、撤销重做
- 手机端优先竖屏；横屏、平板可用但布局会折叠
